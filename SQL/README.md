# Trabalho SQL - Banco de Dados

Este repositório contém uma atividade de consultas SQL usando SQLite com Python.

## Arquivos

- `SQL/atividade_sqlite_select.py`: cria as tabelas `cliente`, `produto` e `venda`, popula dados de exemplo e executa consultas `SELECT`.
- `SQL/loja_select.db`: banco SQLite gerado para a atividade.

## Como executar

```bash
cd SQL
python atividade_sqlite_select.py
```

O script recria o banco `loja_select.db` e exibe as consultas no terminal.
